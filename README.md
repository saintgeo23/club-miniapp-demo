# Club mini-app demo

Личный кабинет клиента салона: один фронт для Telegram Mini App и MAX мини-приложения.
Демо на моковых данных, бренд «Лоск» вымышленный.

## Что внутри

- Вход по номеру телефона: `requestContact` в Telegram и MAX, ручной ввод в браузере.
- Статус клуба с прогрессом до следующего уровня, бонусные карты, быстрые действия,
  активные записи, абонементы (оплата, остаток процедур, заморозка), история визитов
  с пагинацией по 5, оценка визита (при 5★ ведёт на отзыв в картах), реферальная программа.
- Тема берётся из Telegram (`--tg-theme-*`), иначе светлая/тёмная по системе.
- `src/platform.ts` — единственное место, которое знает про мессенджеры.
- `src/config.ts` — тексты, ссылки, контакты менеджера.

## Запуск

```bash
npm install
npm run dev
```

Настоящий API: задать `VITE_API_URL` в `.env.local`, тогда вместо моков пойдёт
`POST {VITE_API_URL}/api/client/profile` с `{ phone }`.

## Подключение к мессенджерам

- Telegram: собрать (`npm run build`), выложить `dist/` на HTTPS, в @BotFather →
  бот → Bot Settings → Menu Button / Configure Mini App → указать URL.
- MAX: в кабинете партнёра на business.max.ru привязать URL мини-приложения к боту.
